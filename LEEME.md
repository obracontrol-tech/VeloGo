# VeloGo — Fase 1 (versión 0.1)

Sube TODO el contenido de esta carpeta a un repositorio nuevo de GitHub (por ejemplo `velogo`) y activa GitHub Pages.

Archivos:
- index.html — la app completa
- manifest.json — para instalarla en el móvil
- sw.js — funciona sin conexión
- icons/ — iconos de la app (192, 512 y maskable)

Qué funciona ya:
- Bienvenida de 3 pantallas (pide el nombre)
- Comunidad: crear salida (día, hora, punto de salida, punto de encuentro), Me apunto, compartir por WhatsApp, Cómo llegar, ranking y puntos
- Rutas: mapa, buscador de lugares, satélite, mi ubicación, hoja "Empieza a planificar"
- Actividades: subir GPX/TCX (distancia, desnivel, tiempo) y puntos
- Perfil: nombre, modo claro
- Alertas de seguridad: 112 y ubicación por WhatsApp

Importante: por ahora los datos se guardan SOLO en el móvil de cada uno.
Las salidas compartidas entre ciclistas llegan en la Fase 2 (Firebase nuevo).
